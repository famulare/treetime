# IQ-TREE 2.4.0 invariant-sites (`+I`) site-rate fixtures

These files were generated by the installed IQ-TREE 2.4.0 ARM64 release. The
alignment is *simulated* under an `+I+G` process with a chosen invariant
proportion so `p_inv` is genuine and non-trivial (many sites carry real
invariant responsibility). This lets us validate the invariant reconstruction
`p_i0 = 1 - sum_k q_k`.

## Simulation

`alignment.fasta` was simulated with `--alisim` under a well-conditioned
`GTR+F+I{0.3}+G4{0.7}` process on the fixed 10-taxon `tree.nwk`, then converted
from the emitted PHYLIP to FASTA:

```sh
iqtree2 --alisim sim_aln -t tree.nwk \
  -m "GTR{2.0,4.0,1.0,1.2,5.0}+F{0.3,0.2,0.2,0.3}+I{0.3}+G4{0.7}" \
  --length 600 --seed 1 -redo -nt 1
# PHYLIP -> FASTA via Bio.AlignIO (phylip-relaxed)
```

## The `+I` mechanism (verified against these fixtures)

The invariant class is **not** a `.sitelh` column: IQ-TREE prints only the `K`
variable rate categories there. The per-site rate-category responsibilities are
reconstructed as `q_k = exp(LnLW_k - LnL)`; for a `+I` model these sum to `<= 1`
and the deficit is the invariant responsibility:

```
p_i0 = max(0, 1 - sum_k q_k)
full responsibility row = [p_i0, q_1, ..., q_K]   (renormalized to sum 1)
category rates          = [0,   r_1, ..., r_K]
```

IQ-TREE reports the invariant as **Category 0 (Relative_rate 0, Proportion =
p_inv)** in the `.iqtree` report table and as **`+I{p_inv}`** in
`best_model.nex`. TreeTime keeps it as an explicit rate-0 category.

Verified on `ig_unpartitioned/` (unpartitioned `+I+G`): mean recovered `p_i0` =
0.3558 vs report `Proportion of invariable sites: 0.356`; the full responsibility
`[p_i0, q]` with rates `[0, r]` reproduces IQ-TREE's `.rate` posterior-mean rates
to `max|delta| = 6.6e-4` (corr 1.0).

## `ig_unpartitioned/` — `GTR+F+I+G4`

```sh
iqtree2 -s alignment.fasta -te tree.nwk -m GTR+F+I+G4 \
  --rate -wslr --prefix generated --seed 1 -redo -nt 1
```

The report fits `Proportion of invariable sites: 0.356`, `Gamma shape alpha:
0.9078`, and prints the Category table with Category 0 at rate 0. The optional
`.rate` cross-check passes for this fixture because IQ-TREE's unpartitioned
`+I+G` `.rate` is the *with-invariant* posterior mean.

## `ir_unpartitioned/` — `GTR+F+I+R4`

```sh
iqtree2 -s alignment.fasta -te tree.nwk -m GTR+F+I+R4 \
  --rate -wslr --prefix generated --seed 1 -redo -nt 1
```

Same invariant reconstruction (mean recovered `p_i0` = 0.3144 vs report `0.3145`).
NOTE: IQ-TREE's `+I+R` `.rate` column reports the *variable-conditional* posterior
mean (rates renormalized by `1 - p_inv`), which is a different convention than the
with-invariant mean TreeTime evaluates. The optional `.rate` cross-check therefore
does NOT match for `+I+R`; omit `rate_file` for this fixture (the loader fails
loud if it is supplied, rather than silently accepting a mismatched convention).

## `ig_partitioned/` — two contiguous `GTR+F+I+G4` partitions

`partitions.nex` is a *charset-only* NEXUS file (a `charpartition` with explicit
models conflicts with `-m`, so `-m GTR+F+I+G4` applies per partition):

```sh
iqtree2 -s alignment.fasta -te tree.nwk -p partitions.nex -m GTR+F+I+G4 \
  --rate -wslr --prefix generated --seed 1 -redo -nt 1
```

The partitioned `best_model.nex` writes `+I{p_inv}+G4{alpha}` per partition
(`first`: `+I{0.386657}+G4{1.15294}`, `second`: `+I{0.2526}+G4{0.568401}`). As
with plain `+G`, there is no per-partition `Category` table in the report and no
per-category rate table survives partition output, so each partition's variable
category rates are recomputed from `alpha` with the mean-method discrete-Gamma
and the invariant is prepended from `+I{p_inv}`. The report's `Speed` column
supplies the per-partition speeds (`0.9236`, `1.1145`) that scale the *variable*
category rates (the rate-0 invariant category stays 0 under any speed). Per-row
per-partition mean `p_i0` matches each `+I{p_inv}` (0.3881 vs 0.386657; 0.2526 vs
0.2526).

Like `+G`, the partitioned `+I+G` `.rate` uses a per-partition variable-
conditional rescaling; omit `rate_file` for the partitioned fixture.
