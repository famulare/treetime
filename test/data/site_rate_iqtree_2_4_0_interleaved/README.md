# IQ-TREE 2.4.0 interleaved site-rate fixture

These files were generated by the installed IQ-TREE 2.4.0 ARM64 release from the
included alignment, fixed tree, and **interleaved** (non-contiguous) codon-position
partitions:

```sh
iqtree2 -s alignment.fasta -te tree.nwk -p partitions_interleaved.nex \
  -m GTR+F+R2 --rate -wslr --prefix generated --seed 1 -redo -nt 1
```

The `-wslr` `.sitelh` output holds per-site, per-category log-likelihoods;
TreeTime reconstructs the rate-category responsibility as
`q_k = exp(LnLW_k - LnL)`.

`partitions_interleaved.nex` maps three charsets by codon position
(`1-50\3`, `2-50\3`, `3-50\3`), so partition-local sites interleave on the global
alignment axis with unequal partition sizes (17, 17, 16). The report records
edge-linked-proportional partition speeds of 0.1936, 2.5699, and 0.1888, while each
partition's raw `.rate` values have mean approximately one.

This complements the contiguous `site_rate_iqtree_2_4_0` fixture: it exercises the
adapter's global-coordinate mapping against real IQ-TREE writer output whose rows do
**not** land in contiguous blocks, and independently reconfirms IQ-TREE's
within-partition rate convention before TreeTime applies partition speeds.
